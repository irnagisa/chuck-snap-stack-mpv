# Chuck Snap Stack

動画・音声・画像ファイルをまとめて管理・再生するデスクトップメディアマネージャ。mpv を内蔵プレイヤーとして使用する、高機能なメディアライブラリアプリです。

## 機能一覧

### 対応メディア形式

| 種別 | 対応形式 |
|---|---|
| 動画 | MP4, MKV, WebM, AVI, MOV, M4V, FLV, WMV |
| 音声 | MP3, FLAC, AAC, WAV, OGG, Opus, M4A, WMA |
| 画像 | JPEG, PNG, GIF, WebP, BMP, TIFF, HEIC, AVIF |
| 字幕 | SRT, ASS, VTT, SUB, SSA |

### ライブラリ管理
- **自動スキャン** — フォルダを指定するだけでメディアを一括インポート。サムネイル自動生成。
- **ファイルウォッチャー** — 監視フォルダへの追加・削除をリアルタイム検知し、ライブラリを自動更新。
- **欠損ファイル検出** — 移動・削除されたファイルを検出して一覧表示。

### 再生・表示
- **mpv 再生** — 動画・音声を mpv で再生。高品質・多フォーマット対応。
- **画像ビューア** — 画像ファイルをアプリ内で表示。コレクション内をナビゲーション可能。
- **再生履歴・進捗保存** — 途中まで観た動画は次回も同じ位置から再開。
- **プレイキュー** — 再生待ちキューを管理して連続再生。
- **キーボードショートカット** — スペースで一時停止、矢印キーでシーク・音量調整など。

### 整理・フィルタリング
- **タグ & カテゴリ** — 色分けタグとカテゴリでメディアを整理。絞り込み表示に対応。
- **星評価** — 5段階の評価を付与してお気に入りを管理。
- **プレイリスト** — 手動プレイリストの作成・並べ替え・連続再生。ドラッグ&ドロップで順序変更。
- **スマートプレイリスト** — タグ・カテゴリ・評価などの条件でメディアを自動抽出。
- **重複検出** — 同じファイルを自動検出してまとめて管理。

### 一括操作
- **一括タグ付与・カテゴリ設定** — 複数のファイルをまとめて整理。
- **一括削除** — 選択したファイルをまとめてライブラリから削除。
- **一括リネーム** — メディアファイルをまとめてリネーム。

### ダウンロード・変換
- **URL ダウンロード** — HTTP 直リンクまたは yt-dlp 経由で動画をダウンロード。進捗表示・キャンセル対応。ダウンロードキューで複数同時管理。
- **AV1 変換** — ffmpeg で動画を AV1 (libsvtav1 + libopus) に変換。ストレージ削減に。

### データ管理
- **バックアップ / 復元** — ライブラリ情報 (メディア・タグ・プレイリスト) を JSON ファイルにエクスポート・インポート。
- **統計** — 総視聴時間、よく観たメディア、高評価のファイル、タグ・カテゴリの使用状況などを確認。

### UI
- **テーマ切り替え** — ダーク / ライト / OS 設定に合わせた自動切り替え。
- **サイドバー** — カテゴリ・プレイリストをサイドバーで素早く切り替え。

## 動作環境

| 項目 | 要件 |
|---|---|
| OS | macOS / Linux |
| mpv | **必須。** 動画・音声の再生に使用。 |
| ffmpeg / ffprobe | **推奨。** サムネイル生成・AV1 変換に使用。 |
| yt-dlp | オプション。YouTube 等からのダウンロードに使用。 |

## インストール

### 1. アプリをダウンロード

[Releases](https://github.com/irihi/chuck-snap-stack/releases) から最新版をダウンロードしてください。

| OS | ファイル形式 |
|---|---|
| macOS | `.dmg` |
| Linux | `.AppImage` / `.deb` |

### 2. 依存ツールをインストール

**macOS (Homebrew)**

```bash
brew install mpv ffmpeg yt-dlp
```

**Linux (Ubuntu/Debian)**

```bash
sudo apt install mpv ffmpeg
pip install yt-dlp   # または公式バイナリを /usr/local/bin に配置
```

## 使い方

### ライブラリのセットアップ

1. アプリ起動後、「フォルダを開く」ボタンでメディアフォルダを選択
2. スキャン完了後、サムネイルが自動生成されます
3. 動画・音声ファイルをクリックすると mpv で再生、画像はビューアで表示

### 設定

右上の歯車アイコンから設定画面を開けます。

| 設定項目 | 説明 | デフォルト |
|---|---|---|
| mpv パス | mpv 実行ファイルのパス | `/opt/homebrew/bin/mpv` (macOS) / `mpv` (Linux) |
| ffmpeg パス | ffmpeg 実行ファイルのパス | `ffmpeg` (PATH) |
| ffprobe パス | ffprobe 実行ファイルのパス | `ffprobe` (PATH) |
| yt-dlp パス | yt-dlp 実行ファイルのパス | 自動検出 |
| テーマ | ダーク / ライト / 自動 | 自動 |

### キーボードショートカット

| キー | 操作 |
|---|---|
| `Space` | 再生 / 一時停止 |
| `←` / `→` | 5秒戻る / 進む |
| `↑` / `↓` | 音量 +5 / -5 |
| `F` | フルスクリーン切り替え |
| `N` / `P` | 次の動画 / 前の動画 |
| `Escape` | モーダルを閉じる |

### URL ダウンロード

1. ツールバーの「ダウンロード」ボタンをクリック
2. 動画の URL を入力
3. yt-dlp を使う場合は「yt-dlp を使用」をオン
4. 「ダウンロード」を押すと進捗バーが表示されます。キャンセルも可能。

### AV1 変換

1. 動画を右クリックして「詳細」→「AV1 変換」
2. 変換中は進捗が表示されます
3. 変換完了後、元ファイルの削除を確認するダイアログが表示されます
4. 変換ファイルは元ファイルと同じディレクトリに `{ファイル名}.av1.mkv` として保存

### バックアップ

- ツールバーの「エクスポート / インポート」から、ライブラリデータを JSON ファイルに保存・復元できます。
- 別の PC への移行やバックアップにご利用ください。
