# Chuck Snap Stack

動画・音声・画像ファイルをまとめて管理・再生するデスクトップメディアマネージャ。mpv を内蔵プレイヤーとして使用する、高機能なメディアライブラリアプリです。

## 機能一覧

### 対応メディア形式

| 種別 | 対応形式 |
|---|---|
| 動画 | MP4, MKV, WebM, AVI, MOV, M4V, FLV, WMV, MPG, MPEG |
| 音声 | MP3, FLAC, AAC, WAV, OGG, Opus, M4A, WMA |
| 画像 | JPEG, PNG, GIF, WebP (アニメーション含む), BMP, TIFF, HEIC, AVIF |
| 字幕 | SRT, ASS, VTT, SUB, SSA |

### ライブラリ管理
- **自動スキャン** — フォルダを指定するだけでメディアを一括インポート。サムネイル (WebP) を自動生成。
- **ファイルウォッチャー** — 監視フォルダへの追加・削除・移動をリアルタイム検知し、ライブラリを自動更新。
- **欠損ファイル検出** — 移動・削除されたファイルを検出して一覧表示・クリーンアップ。
- **重複検出** — 同じファイルを自動検出してまとめて管理。

### Inbox & スタック管理
- **Inbox** — 未整理ファイルを自動で Inbox に収容。カテゴリ・評価・タグがそろったら自動卒業。
- **スタック表示** — ソース別・日付別・未設定メタデータ別・ディレクトリ別などの基準でまとめて表示。
- **クイックソート** — 10件単位でスタックを素早く整理する一括メタデータ付与モード。

### 再生・表示
- **mpv 再生** — 動画・音声を mpv で再生。高品質・多フォーマット対応。
- **画像ビューア** — 画像ファイルをアプリ内で表示。コレクション内をナビゲーション可能。
- **再生履歴・進捗保存** — 途中まで観たメディアは次回も同じ位置から再開。
- **プレイキュー** — 再生待ちキューを管理して連続再生。シャッフル・ループモード対応。
- **A-B ループ** — 区間を指定してリピート再生。
- **チャプター** — 動画のチャプターメタデータに対応。
- **ミニプレイヤー** — フローティング小窓で再生しながら別の操作が可能。
- **再生速度調整** — 0.25x〜2x の速度調整。

### 整理・フィルタリング
- **タグ & タグカテゴリ** — 色・アイコン付きタグで整理。タグをカテゴリでグループ化可能。
- **カテゴリ** — 階層カテゴリ (親子関係) でメディアを分類。ディレクトリ名を自動カテゴリ化するオプション付き。
- **星評価** — 5段階の評価を付与してお気に入りを管理。
- **高度なフィルタ** — テキスト・カテゴリ・タグ (AND/OR)・評価・視聴状態・メディア種別・再生時間範囲での絞り込み。
- **ソート** — 日付・評価・再生時間・タイトル・視聴回数でソート。

### プレイリスト
- **手動プレイリスト** — 作成・並べ替え (ドラッグ&ドロップ) ・連続再生。
- **スマートプレイリスト** — タグ・カテゴリ・評価などの条件を保存して動的に抽出。

### 一括操作
- **一括タグ付与・カテゴリ設定・評価変更** — 複数のファイルをまとめて整理。
- **一括削除** — 選択したファイルをまとめてライブラリ・ファイルシステムから削除。
- **一括リネーム** — メディアファイルをまとめてリネーム。
- **一括プレイリスト追加** — 複数ファイルをプレイリストに一括追加。

### AI タグ付け (WD Tagger)
- **自動タグ提案** — サムネイルを WD ViT Tagger v3 (Danbooru タガー) で解析し、タグを自動提案。
- **閾値設定** — 信頼度スコアでフィルタリング (デフォルト 0.35)。
- **既存タグとのマッチング** — AI 提案とユーザー定義タグを照合し、使えるタグを強調表示。
- **モデル管理** — アプリ内でモデルをダウンロード・SHA-256 検証。

### ダウンロード・変換
- **URL ダウンロード** — HTTP 直リンクまたは yt-dlp 経由で動画をダウンロード。進捗表示・キャンセル対応。ダウンロードキューで複数同時管理。
- **AV1 変換** — ffmpeg で動画を AV1 (libsvtav1 + libopus) に変換。品質 (CRF) ・プリセット設定可能。

### データ管理
- **バックアップ / 復元** — ライブラリ情報 (メディア・タグ・プレイリスト・設定) を JSON ファイルにエクスポート・インポート。
- **統計** — 総視聴時間・よく観たメディア・高評価ファイル・タグ/カテゴリ使用状況を確認。
- **カテゴリ移行** — カテゴリ階層の再編・統合。

### UI
- **グリッド / リスト表示切替** — サムネイル表示と一覧表示を切り替え。
- **テーマ切り替え** — ダーク / ライト / OS 設定に合わせた自動切り替え。
- **多言語対応** — 日本語 / English / 中文 (簡体字) に対応。
- **ドラッグ&ドロップ** — ファイルをドロップしてインポート、プレイリスト内での並べ替えに対応。
- **サイドバー** — カテゴリ・プレイリスト・監視フォルダをサイドバーで素早く切り替え。

## 動作環境

| 項目 | 要件 |
|---|---|
| OS | macOS / Linux |
| mpv | **必須。** 動画・音声の再生に使用。 |
| ffmpeg / ffprobe | **推奨。** サムネイル生成・AV1 変換に使用。 |
| yt-dlp | オプション。YouTube 等からのダウンロードに使用。 |

## インストール

### 1. アプリをダウンロード

[Releases](https://github.com/irihi/chuck-snap-stack/releases) から最新版をダウンロードしてください。

| OS | ファイル形式 |
|---|---|
| macOS (Apple Silicon) | `.dmg` |
| macOS (Intel) | `.dmg` |
| Linux | `.AppImage` / `.deb` |

### 2. 依存ツールをインストール

**macOS (Homebrew)**

```bash
brew install mpv ffmpeg yt-dlp
```

**Linux (Ubuntu/Debian)**

```bash
sudo apt install mpv ffmpeg
pip install yt-dlp   # または公式バイナリを /usr/local/bin に配置
```

## 使い方

### ライブラリのセットアップ

1. アプリ起動後、「フォルダを開く」ボタンでメディアフォルダを選択
2. スキャン完了後、サムネイルが自動生成されます
3. 動画・音声ファイルをクリックすると mpv で再生、画像はビューアで表示

### 設定

右上の歯車アイコンから設定画面を開けます。

| 設定項目 | 説明 | デフォルト |
|---|---|---|
| mpv パス | mpv 実行ファイルのパス | `/opt/homebrew/bin/mpv` (macOS) / `mpv` (Linux) |
| ffmpeg パス | ffmpeg 実行ファイルのパス | `ffmpeg` (PATH) |
| ffprobe パス | ffprobe 実行ファイルのパス | `ffprobe` (PATH) |
| yt-dlp パス | yt-dlp 実行ファイルのパス | 自動検出 |
| テーマ | ダーク / ライト / 自動 | 自動 |
| 言語 | 日本語 / English / 中文 | 日本語 |

### URL ダウンロード

1. ツールバーの「ダウンロード」ボタンをクリック
2. 動画の URL を入力
3. yt-dlp を使う場合は「yt-dlp を使用」をオン
4. 「ダウンロード」を押すと進捗バーが表示されます。キャンセルも可能。

### AV1 変換

1. 動画を右クリックして「詳細」→「AV1 変換」
2. CRF・プリセットを設定して変換開始
3. 変換中は進捗が表示されます
4. 変換完了後、元ファイルの削除を確認するダイアログが表示されます
5. 変換ファイルは元ファイルと同じディレクトリに `{ファイル名}.av1.mkv` として保存

### AI タグ付け

1. 設定画面から「AI モデルをダウンロード」
2. メディアの詳細画面で「AI 解析」ボタンをクリック
3. 提案されたタグを確認し、追加するタグを選択

### バックアップ

- ツールバーの「エクスポート / インポート」から、ライブラリデータを JSON ファイルに保存・復元できます。
- 別の PC への移行やバックアップにご利用ください。
