  ---
  追加機能の提案

  優先度: 高（実装コストが低く効果が大きい）

  1. ホバープレビュー（サムネイルストリップ）
  - グリッド上でホバー時に複数フレームのストリップをアニメーション表示
  - capture_frame_at コマンドが既存なので数フレームを事前生成するだけ

  2. ブックマーク / タイムスタンプメモ
  - 動画内の特定時刻にメモを付ける
  - DB: video_bookmarks(video_id, timestamp, note) テーブル追加
  - mpv の A-B ループ機能と連動させると強力

  3. OS ネイティブ通知 ✅
  - ダウンロード完了・トランスコード完了・インポート完了時に macOS 通知
  - tauri-plugin-notification で実装済み

  4. 視聴統計ダッシュボード
  - watched_at と watch_count が既にある → 日別・週別の視聴グラフ
  - タグ別・カテゴリ別の比率チャート
  - 現在の StatsModal の機能拡張として実装可能

  5. M3U プレイリストのエクスポート
  - 通常プレイリスト → .m3u ファイル出力
  - 他のメディアプレイヤーとの連携が可能

  ---
  優先度: 中（価値が高いが実装コストも中程度）

  6. チャプターナビゲーション UI
  - get_chapters コマンドが既存だが UI がない
  - 詳細パネルにチャプターリストを表示し、クリックで mpv をシーク

  7. 字幕パネル
  - scan_subtitle_files は実装済みだが詳細パネルとの連携が弱い
  - load_subtitle コマンドと組み合わせて、字幕ファイル選択 UI を追加

  8. タグのエイリアス / 関連タグ
  - タグ間の similar_to 関係を DB で管理
  - 「このタグを付けたなら、関連タグ X も追加しますか？」のサジェスト

  9. メディアノート
  - メディアごとのテキストメモ欄（save_text_file/read_text_file が既存）
  - 詳細パネルに Markdown 簡易エディタを追加

  10. バッチ名前変更（パターン置換）✅
  - BulkRenameModal として実装済み
  - 既存の rename_video_file を活用

  ---
  優先度: 低（面白いが実装コストが高い）

  11. 音声波形表示
  - media_type='audio' のファイルに対してサムネイルの代わりに波形を表示
  - ffmpeg で波形画像を生成 (showwavespic フィルタ)

  12. メディア比較ビュー
  - 重複検出後に 2 画面並べて比較できるモーダル
  - 現在の DuplicatesModal の拡張

  13. iCloud / ネットワーク共有での DB 同期
  - 設定ファイルを iCloud Drive に保存する簡易同期
  - 複数 Mac での設定共有
