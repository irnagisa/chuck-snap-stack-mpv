# コンセプト

このアプリケーションは、ファイルを囲い込むことを目的としたライブラリではない。

ユーザーが所有しているファイルを、既存のディレクトリ構成を維持したまま管理し、閲覧し、整理するための管理レイヤーを提供する。

実ファイルの所有者は常にユーザーであり、アプリケーションはファイルを複製しない。

アプリケーションを削除しても、ディレクトリ構成やファイルそのものは失われない。

カテゴリは物理ディレクトリと対応し、アプリケーション上での分類結果はそのままファイルシステムにも反映される。

カテゴリとディレクトリの対応は、Watch Directory ごとに設定できる。

Sync Mode では、カテゴリ変更はファイルの物理移動を伴う。
アプリケーションを削除した後もディレクトリ構成にカテゴリが反映される。

Virtual Mode では、カテゴリ変更は DB のみを更新する。
物理ファイルの場所はカテゴリの変更に影響されない。
アプリケーションを削除するとカテゴリ情報は失われる。

どちらのモードを選択するかはユーザーが決定する。
デフォルトは Sync Mode である。

一方で、状態や作業進捗はディレクトリとは切り離して管理する。

カテゴリは永続的な所属を表し、状態は一時的なタスクを表す。

この二つを分離することで、ファイルシステムのシンプルさを維持しながら、柔軟な管理機能を実現する。

新しく追加されたファイルは Inbox に入り、タグ、評価、カテゴリ設定などの整理作業を通じて徐々に完成していく。

整理作業そのものを支援し、未処理や放置を減らすことも、このアプリケーションの役割である。

大量のファイルを保管することが目的ではない。

必要なファイルを見つけやすくし、管理しやすくし、長期的に維持できる状態を作ることを目的とする。

Explorer や Finder と競合するものではなく、それらを補完する存在である。

特定のアプリケーションに依存しないファイル構成を維持しながら、管理に必要な機能だけを追加する。

ファイルシステムを主役とし、アプリケーションはその上に存在する管理UIである。
