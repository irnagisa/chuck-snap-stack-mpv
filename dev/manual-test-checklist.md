# 手動テストチェックリスト

バージョン 1.0.0 リリース前の主要ワークフロー手動 E2E テスト用チェックリスト。

---

## 1. 起動・基本動作

- [ ] `pnpm tauri dev` でアプリが正常起動する
- [ ] ダークモード / ライトモードが切り替わる
- [ ] ウィンドウのリサイズ・最大化が正常動作する
- [ ] 再起動後に前回の状態（選択中カテゴリ等）が復元される

---

## 2. ライブラリ管理

### 2.1 ディレクトリスキャン

- [ ] 設定 → 監視フォルダを追加できる
- [ ] スキャン実行でメディアファイルが DB に登録される
- [ ] 動画 / 音声 / 画像が `media_type` で正しく区別される
- [ ] サムネイルが生成されてグリッドに表示される
- [ ] サムネイル生成プログレスバーが表示・完了後に消える
- [ ] スキャン済みフォルダを削除した際の警告/処理が正常
- [ ] `use_dir_as_category` ON でスキャンするとフォルダ名がカテゴリとして自動作成される

### 2.2 ライブラリ表示

- [ ] グリッドビュー / リストビューが切り替わる
- [ ] サムネイルホバーで動画プレビューが再生される（動画のみ）
- [ ] ファイルが存在しない場合に「missing」バッジが表示される
- [ ] 欠損ファイルの一覧モーダル（MissingFilesModal）が開く

### 2.3 フィルタリング・検索

- [ ] テキスト検索でタイトル・パスが絞り込まれる
- [ ] カテゴリサイドバーでクリックするとフィルタされる
- [ ] タグサイドバーでクリックするとフィルタされる
- [ ] 複数タグを選択するとAND絞り込みになる
- [ ] 評価（星）フィルタが機能する
- [ ] `未視聴` / `視聴済み` フィルタが機能する
- [ ] メディアタイプ（動画 / 音声 / 画像）フィルタが機能する
- [ ] ソート（名前 / 日付 / 評価 / 再生数）が切り替わる
- [ ] フィルタのリセットが機能する

### 2.4 メディア詳細・編集

- [ ] サムネイルダブルクリックまたは詳細ボタンで VideoDetailModal が開く
- [ ] タイトル編集が保存される
- [ ] 評価（星）の変更が保存される
- [ ] カテゴリの割り当て・変更が保存される
- [ ] タグの追加・削除が保存される
- [ ] タグ入力でオートコンプリートが表示される
- [ ] 類似メディア（pHash）が表示される（計算済みの場合）
- [ ] ファイルパス・サイズ・時間・解像度などのメタデータが正しく表示される
- [ ] 「ファインダーで表示」がファイルを Finder で開く（macOS）

### 2.5 コンテキストメニュー

- [ ] 右クリックでコンテキストメニューが表示される
- [ ] 「再生」でファイルが mpv で再生される
- [ ] 「プレイリストに追加」が機能する
- [ ] 「削除」でDeleteVideoModal が開き、確認後 DB から削除される
- [ ] 「Inbox へ移動」でステータスが inbox に変わる
- [ ] 「カテゴリ変更」が機能する

### 2.6 バッチ操作

- [ ] チェックボックスで複数メディアを選択できる
- [ ] 全選択 / 全解除が機能する
- [ ] BatchActionBar が選択時に表示される
- [ ] 一括カテゴリ変更（BulkCategoryModal）が保存される
- [ ] 一括タグ付け（BulkTagModal）が保存される
- [ ] 一括評価変更（BulkRatingModal）が保存される
- [ ] 一括リネーム（BulkRenameModal）がプレビュー表示され適用される
- [ ] 一括削除（BulkDeleteModal）が確認後に実行される

### 3.3 キューパネル

- [ ] キュー項目の並び替えが機能する
- [ ] キュークリアが機能する

### 3.4 ミニプレイヤー

- [ ] ミニプレイヤーウィンドウを開ける
- [ ] ミニプレイヤーの再生 / 一時停止が機能する

## 4. Inbox / QuickSort

### 4.1 Inbox ビュー

- [ ] Inbox タブでステータスが inbox のメディアが表示される

### 4.2 QuickSort ナビゲーション

- [ ] 「前」「次」ボタンでナビゲートできる

- [ ] Escape キーでスタック一覧に戻る
- [ ] プログレスバーが進捗に合わせて更新される
- [ ] カウンター（x / n）が正しく表示される

### 4.3 QuickSort 操作

- [ ] 「再生」ボタンで mpv が起動する
- [ ] 「詳細を開く」で VideoDetailModal が開く
- [ ] サムネイルダブルクリックで再生される
- [ ] 右ペインの VideoOrganizerPanel でカテゴリ・タグ・評価を設定できる
- [ ] 「→ カテゴリ化」でフォルダ名を元にカテゴリが自動作成・割り当てされる
- [ ] 「整理完了」で現在のアイテムが active に変わり次へ進む
- [ ] 「スタック全件を整理完了にする」でスタック全体が active になる

## 優先度メモ

| 優先度 | ワークフロー |
|---|---|
| 高 | ライブラリスキャン、メディア再生、タグ・カテゴリ編集、QuickSort |
| 中 | ダウンロード、プレイリスト、設定保存 |
| 低 | AI タグ提案、pHash、トランスコード、エクスポート |
